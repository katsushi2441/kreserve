# kreserve — 予約・受付システム

サロン・クリニック・士業向けの予約ページ＋管理画面。
**PHPのみ・DBなし・レンタルサーバーにFTPで置くだけ。**

- お客様: メニュー → 日 → 時間 → お名前 の4ステップ予約。キャンセルURL発行・確認メール
- お店: 日別一覧 / 検索 / 取消・復活 / 電話予約の手動追加 / 月別CSV
- 設定(メニュー・営業時間・定休日・受付ルール)は `kreserve_config.php` に集約 —
  **Claude Code等のAIエージェントに頼んで安全に変えられる**(skills/・docs/ 同梱)
- ダブルブッキング防止: 空き判定と書き込みを同じflockロック内で実施
- PHP 5.6〜8.3 / 依存ゼロ / 全部で約800行の「全部読めるサイズ」
